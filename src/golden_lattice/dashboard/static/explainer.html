Golden Lattice
Cognition emerges between models, not inside the strongest one.
A CLI that runs Opus, Sonnet, and Haiku as peers on the same prompt — and produces a co-authored response that none of them would have produced alone.

The pattern it refuses
Haiku → Sonnet → Opus — the cheap-to-strong escalation pipeline
The cost and speed curves of a model family pull hard toward that pipeline. Golden Lattice is the deliberate refusal of it — in favor of parallel, symmetric authorship. There is no goal line, no judge, no strongest model with the final word. The territory the lattice explores only becomes visible when collapse is refused.
The Four Refusals
Not constraints. Structural commitments that make the collapse modes impossible to construct.
01
No authority gradient
No model finalizes, overrides, or judges another's output.
enforced · SynthesisArtifact has no model_id field. Claim refuses construction with source_phase = SYNTHESIS. Synthesis cannot attribute to a model, structurally.
02
Symmetric visibility
All three models see the same prompt, the same peer outputs, the same dialogue state.
enforced · Session requires phase_1 keyed by every invited model with a consistent prompt_hash. Asymmetric framing is refused at construction.
03
Contribution parity
Each model's distinct perspective is preserved through synthesis. Measurable, not aspirational.
enforced · A model below 15% on all three contribution shares is flagged. Persistent flagging across sessions means the protocol is collapsing toward routing.
04
Irreducibility preservation
No model's contribution can be fully subsumed without trace. The trace itself is the proof.
enforced · Session refuses construction if Phase 4's claim_trace does not cover every Phase 1 claim_id. Each entry is present, modified-with-text, or omitted-with-reason.
The Protocol
Five phases. Each one constrained from below before it can run.
00
Investigation optional
Each model independently proposes up to three searches; the rule-based union is executed by a non-model tool and frozen as shared evidence before generation. A deterministic timestamp grounds the session first.
01
Independent Generation parallel · blind
All three models answer the same prompt simultaneously, unaware of each other. Each tags a focus and a confidence, and — in its idle time — reflects on its own strongest and weakest claim.
02
Cross-Reading & Tagging structured
Each model reads its peers and emits structured agreements, disagreements, and missing claims — then tags every claim from closed vocabularies. Free-form prose is rejected.
03
Structured Dialogue three channels
One round, hard caps: critique what is weak, augment what is missing, converge where alignment is real. Models cannot use channels outside this set. The constraint is the feature.
04
Synthesis rule-based
Deterministic given its inputs — no fourth model judges the other three. Every claim is preserved or omitted-with-reason, agreement is elevated, dispute is surfaced inline, and parity is measured per session.
Falsification
The architecture earns its premise — or it doesn't. Three measurable conditions decide.
i. Lattice outputs are preferred to single-model outputs by independent evaluators.
ii. Lattice outputs preserve more distinct insights than any single model produced alone.
iii. Contribution parity stays above 15% per model across sessions.
all three →  the architecture earns its premise. It is truly co-authored.
first two →  something good, but we cannot claim co-authorship.
only first →  a more expensive single model.
none →  routing with extra steps.
